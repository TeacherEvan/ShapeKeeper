# Security Policy

## Supported Versions

ShapeKeeper currently follows the `4.x` release line.

| Version | Supported |
| --- | --- |
| 4.x | :white_check_mark: |
| < 4.0 | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities privately to the repository owner rather than opening a public issue. Include a clear description, affected component/version, reproduction steps, and any relevant logs or proof-of-concept material.

Please do not include real user credentials, session identifiers, or other sensitive personal information in a report.
